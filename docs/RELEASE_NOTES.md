# SkinStudio 2.8.0

- 新增 WorkBuddy Electron 桌面版换肤，支持现有主题、原生浅深色同步及恢复官方外观。
- 接入独立应用配置、外观微调、保存微调、应用状态、错误重试和兼容性验收。
- 适配聊天、输入框、菜单和独立设置窗口；清除分栏底色遮挡，默认保持壁纸清晰。
- WorkBuddy 调试端口只设置在子进程；无法访问高权限实例时明确提示。日志不记录页面 URL 中的账户参数。
- 保留单文件 EXE 发行方式，以及既有四款应用的配置、主题和微调。

验证：70 项模拟工作页面检查，WorkBuddy 5.8.3 独立实例的真实聊天、菜单、输入区及设置窗口浅深色检查；源码界面和单文件 EXE 自检。代码块、分栏拖动和上下文面板尚未完成 WorkBuddy 实机验收，详见 COMPATIBILITY.md。

# SkinStudio 2.7.2

安装包只提供可直接运行的 `SkinStudio-v2.7.2.exe`，无需下载或解压压缩包。

- 整理源码、运行和构建命令、单文件打包模板、内置资源、文档及测试目录，仓库根目录保持清晰。
- 构建输出统一在 build/ 和 dist/，本地配置、主题、日志和研究资料独立归档，均不上传。
- 更新源码运行、CLI、验证及发布脚本的路径引用；源码和 CLI 与 EXE 默认共用 Windows 用户数据，支持指定独立数据目录。
- 保留四应用换肤、管理器界面皮肤、外观微调、主题卡片和兼容性验收。升级后原设置和主题继续保留。

验证包括 56 项模拟工作页面回归、源码界面、独立 EXE、缓存修复、含空格路径、不同工作目录和配置隔离检查。实机兼容性覆盖范围见 COMPATIBILITY.md，未将模拟测试算作全部实机通过。
